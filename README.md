# BabyT Rewards

The public dashboard at https://babytonsol.com/ replaces the former domain redirect.
Static HTML, CSS and JavaScript display aggregate data from the separate Deno monitoring service.
No private key, API key or transaction signer is included in this repository.
The interface distinguishes proposed rewards and disabled payouts from confirmed claims.
Creator-source balances may include fees from other tokens. USD amounts are indicative.
